# Система умного поиска

## Обзор архитектуры

Система использует гибридный подход, объединяя BM25 полнотекстовый поиск и векторный поиск для повышения релевантности результатов.

## Компоненты поиска

### BM25 поиск (OpenSearch)
- **Назначение**: Точный поиск по ключевым словам
- **Индекс**: `messages_bm25`
- **Поля**: `message_id`, `text`, `type`, `date`
- **Преимущества**: Быстрый поиск точных совпадений, понятная релевантность

### Векторный поиск (Qdrant)
- **Назначение**: Семантический поиск по смыслу
- **Коллекции**: 
  - `messages_text_vectors` (384 измерения, косинусное расстояние)
  - `images_vectors` (512 измерений, косинусное расстояние)
- **Преимущества**: Поиск по синонимам, понимание контекста

## Система генерации эмбеддингов

### Микросервис эмбеддингов
- **Файл**: `organizer_microservice_embeddings/app.py`
- **Фреймворк**: FastAPI
- **Модель**: `sentence-transformers/all-MiniLM-L6-v2`
- **Размерность**: 384
- **Нормализация**: Включена
- **Эндпоинты**: 
  - `POST /embed` - текстовые эмбеддинги
  - `POST /embed-image` - визуальные эмбеддинги

### OCR сервис (локальный)
- **Файл**: `organizer_backend/ocrService.js`
- **Технология**: Node.js + Tesseract
- **Языки**: русский, английский
- **Интеграция**: встроен в основную систему

### Типы эмбеддингов
1. **Текстовые эмбеддинги** (384D)
   - Модель: all-MiniLM-L6-v2
   - Назначение: Семантический поиск по текстовым сообщениям
   - Статус: ✅ Реализован

2. **Визуальные эмбеддинги** (512D)
   - Модель: ResNet50 (pretrained)
   - Назначение: Поиск по визуальному содержимому изображений
   - Статус: ✅ Реализован

3. **OCR текст из изображений**
   - Движок: Tesseract
   - Назначение: Извлечение текста для последующего семантического поиска
   - Статус: ✅ Реализован

## Гибридный поиск

### Алгоритм работы
1. Параллельный BM25 и векторный поиск
2. Нормализация оценок
3. Комбинированная оценка: `combined = vecScore * 0.6 + bmScore * 0.4`
4. Сортировка по релевантности

### Весовые коэффициенты
- Векторный поиск: 60%
- BM25 поиск: 40%

## Текущее состояние системы

### Что работает ✅
- OpenSearch индекс для BM25
- Qdrant коллекции для текстовых (384D) и изображений (512D) векторов
- Микросервис генерации эмбеддингов с поддержкой текста и изображений
- **Локальный OCR сервис** на Node.js + Tesseract
- Гибридный поиск с реальными эмбеддингами и fuseResults
- Автоматическая индексация новых сообщений
- Поддержка поиска по типам (all/text/image)
- Получение полных данных из Cassandra для результатов поиска

### Что реализовано 🚀
- **Текстовые сообщения**: Полная индексация в OpenSearch + Qdrant
- **Изображения**: Локальный OCR + текстовые и визуальные эмбеддинги
- **Гибридный поиск**: BM25 (40%) + векторный поиск (60%) через fuseResults
- **Микросервис**: Единый сервис для эмбеддингов (порт 8000)
- **Локальный OCR**: Встроен в основную систему без отдельных микросервисов
- **API**: Единый эндпоинт `/search` с параметром `searchType`
- **Интеграция с Cassandra**: Полные данные сообщений в результатах поиска
